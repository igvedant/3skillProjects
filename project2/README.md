# Project 2: Developer Portfolio Website

A modern, responsive personal developer portfolio website designed for Vedant Singh, Software Engineer specializing in MERN stack development and AI agent integration.

## 🌟 Overview
This portfolio showcases professional work, technical skills, engineering internship experience, and key projects through a glassmorphism dynamic dark-themed design.

## 🛠️ Tech Stack
- **HTML5**: Semantic markup structure.
- **CSS3 & Tailwind CSS**: Modern styling, custom glassmorphism components, gradient animation keyframes.
- **JavaScript (ES6+)**: Interactive mobile navigation menu and scroll animations.
- **FontAwesome & Google Fonts**: Modern icon sets and typography.

## 📂 Project Structure
```text
project2/
├── index.html         # Landing page (Hero, About, Skills & Contact)
├── experience.html    # Engineering Experience & Internship Timeline
├── projects.html      # Portfolio Projects Showcase
├── styles.css         # Custom animations & glassmorphism tokens
└── script.js          # Interactive JavaScript logic
```

## 🚀 How to Run
Since this is a client-side web project:
1. Open `index.html` directly in any web browser, or
2. Use a live server extension (e.g., VS Code Live Server) to host locally.
